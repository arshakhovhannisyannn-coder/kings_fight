# Արքաների Մարտ

Մարտավարական քարտախաղ՝ **ինտելեկտուալ հակառակորդով**, հայոց պատմության թեմայով։ Դիպլոմային աշխատանք՝ «Ինտելեկտուալ հակառակորդով տրամաբանական խաղի ծրագրային միջոցի մշակումը և իրականացումը»։ Տարբերակ՝ **1.2**։

Ամեն ռաունդ խաղացողը և AI-ը միաժամանակ քարտեր են դնում 7×9 դաշտում (պլանավորում), հետո սկսվում է մարտը. երկու կողմի զորքերը կամուրջներով անցնում են գետը և գրոհում հակառակորդի աշտարակները։ Նպատակը թշնամու Արքայի ամրոցի ավերումն է կամ 20 ռաունդից հետո առավելությունը։

Ընկերներին ուղարկելու համար՝ [docs/FRIENDS.md](docs/FRIENDS.md)։

## Ինչ կա խաղում

- **Երեք մակարդակի AI.** Հեշտ (կանոններ), Միջին (Minimax + Alpha-Beta), Դժվար (Monte Carlo Tree Search)։
- **«AI-ը ինչ է մտածում» վահանակ.** ալգորիթմը, դիտարկված վիճակների թիվը, լավագույն 3 թեկնածուները (նաև դաշտում՝ համարակալված նշաններով), հայերեն բացատրություն, AI-ի գնահատած հաղթելու հավանականության գծապատկեր և «Ինչպե՞ս է աշխատում» բացատրական պատուհան։
- **Օրիգինալ նկարներ.** բոլոր քարտերը, զորքերը, աշտարակները, դաշտը և մենյուի տեսարանը նկարված են կոդով (SVG). ոչ մի նկար կամ ձայն ներբեռնված չէ։
- **Անիմացիաներ և ձայն.** արկեր, հարվածներ, վնասի թվեր, աշտարակների փլուզում, ռաունդի ազդագրեր. ձայնային էֆեկտները և երաժշտությունը սինթեզվում են Web Audio-ով։
- **Արշավ.** 7 գլուխ × 3 մարտ՝ Հայկ Նահապետից մինչև 1918 թ. Մայիսյան հերոսամարտեր. նկարազարդ քարտեզ, բոսեր, հերոսների բացում, աստղեր։ Առաջին մարտը ինտերակտիվ ուսուցում է։
- **Ազատ մարտ**, կապուկի խմբագրիչ, քարտերի հավաքածու՝ պատմական տեղեկագրով, «Ինչպես խաղալ» էջեր, վիճակագրություն, կարգավորումներ, առաջընթացի պահպանում։
- **Ինքնախաղ և փորձեր** դիպլոմայինի համար (AI-ն AI-ի դեմ, առանց գրաֆիկական միջերեսի)՝ աղյուսակներով և SVG գծապատկերներով։

## Կառավարում

| Գործողություն | Ինչպես |
| --- | --- |
| Ընտրել քարտ | սեղմել քարտին կամ `1`–`4` |
| Դնել քարտը | սեղմել ընդգծված վանդակին կամ քաշել քարտը դաշտ |
| Չեղարկել ընտրությունը | `Esc` կամ աջ կոճակ |
| «Պատրաստ է» | `Space` կամ `Enter` |
| Տեղեկություն | `I` (մկնիկը քարտի կամ զորքի վրա), աջ կոճակ զորքի վրա, քարտի «i» կոճակ |
| Ձայն | `M` |
| Ամբողջ էկրան | `F11` |

Քարտը դաշտի վրա պահելիս երևում է զորքի ուրվականը, հարձակման հեռահարությունը և առաջին քայլերի սլաքը. «Վահագնի կրակի» դեպքում՝ 2×2 տարածքը և թշնամիների կյանքը հարվածից հետո։

## Պահանջներ

- Windows 10/11
- [Node.js](https://nodejs.org) 20 կամ ավելի նոր (ստուգված է 24-ով)

## Տեղադրում և գործարկում

```
npm install
npm start
```

Բացվում է խաղի պատուհանը (Electron)։ Այլընտրանք՝ `npm run serve` և բրաուզերում բացել http://127.0.0.1:5173/ ։

## Թեստեր

```
npm test
```

54 ավտոմատ թեստ. ռաունդի կառուցվածք (պլանավորում + մարտ), ոսկի և պարգևներ, քարտերի սահմանափակում, ձեռքի շրջանառություն, գոտիներ, կամուրջներ և շարժում, թիրախավորում, բոլոր քարտերի ունակությունները, հաղթանակի պայմաններ, կապուկի ստուգում, AI-ի օրինական քայլեր ժամանակի սահմանում, դետերմինիզմ, տեղադրման նախադիտում, պահպանման ֆայլի միգրացիա, վիճակագրություն, «մարդանման» ինքնախաղային գործակալ, նկարների ամբողջականություն։

Ինտերֆեյսի ավտոմատ ստուգում (բացում է հավելվածը, անցնում է ուսուցման բոլոր քայլերը, ստուգում է քաշել-գցելը, ստեղները, կարգավորումները, ձայնի անջատումը, խաղում է ամբողջական մարտեր բոլոր մակարդակների դեմ և պահում է սքրինշոթեր `docs/screenshots/`-ում).

```
npx electron tools/ui-smoke.mjs
npx electron tools/ui-smoke.mjs --quick --battles=10
```

Երկրորդ հրամանը բաց է թողնում ամբողջական մարտերը և ստուգում է, որ 10 հաջորդական մարտից հետո հիշողության մեջ ոչինչ չի մնում։ Ստուգումն աշխատում է էկրանից դուրս (առանց պատուհանի). `--visible` պարամետրով բացվում է իրական պատուհան։ Դասավորության ստուգում տարբեր չափերի համար՝ `npx electron tools/layout-shots.mjs <պանակ>`։

## Ինքնախաղ (AI ընդդեմ AI)

```
npm run selfplay -- --a=hard --b=medium --games=40 --seed=1 --mctsMs=1000 --swapSides
```

| Պարամետր | Նշանակություն |
| --- | --- |
| `--a`, `--b` | մակարդակները՝ `easy`, `medium`, `hard`, `human` (սկսնակ խաղացողի մոդել) |
| `--games` | խաղերի թիվը |
| `--seed` | սերմ (նույն սերմը → նույն խառնումները) |
| `--mctsMs` / `--mctsIters` | «Դժվար»-ի բյուջեն՝ միլիվայրկյան կամ իտերացիա մեկ քայլի համար |
| `--medDepth`, `--medMs` | «Միջին»-ի խորությունը / ժամանակը |
| `--deckA`, `--deckB` | կապուկներ՝ `starter`, `cavalry`, `archers`, `fortress`, `heroes`, `boss1`…`boss7` կամ քարտերի ցուցակ ստորակետերով |
| `--swapSides` | կողմերի և առաջին պլանավորողի հերթափոխում |
| `--quiet` | առանց յուրաքանչյուր խաղի տողի |

Արդյունքը տպվում է էկրանին և պահվում `docs/experiments/selfplay_*.json` ֆայլում։ Կանոնների տարբերակների արագ համեմատություն հավասարակշռության համար՝ `npm run balance`։

## Փորձեր (դիպլոմայինի աղյուսակներ)

```
npm run experiments
```

Ստեղծում է հայերեն աղյուսակներ (`.md`), `.csv` ֆայլեր և `.svg` գծապատկերներ `docs/experiments/` պանակում. մակարդակների համեմատություն, MCTS-ի ուժը ըստ ժամանակի, առաջին պլանավորողի առավելություն, քարտերի հավասարակշռություն, գնահատման կշիռներ, կանոնների տարբերակներ, մարտի պահերի քանակ։ Ավելի մեծ ընտրանք՝ `npm run experiments -- --scale=2`, մեկ փորձ՝ `npm run experiments -- --only=7`։

## Windows-ի `.exe` կառուցում

```
npm run icon
npm run dist
```

`npm run icon`-ը նկարում է խաղի զինանշանը և ստեղծում `build/icon.ico`, `build/icon.png`, `assets/icon.png` ֆայլերը։ `npm run dist`-ը `dist/` պանակում ստեղծում է `ArqaneriMart-1.4.0-portable.exe` (առանց տեղադրման) և `ArqaneriMart-1.4.0-setup.exe` (տեղադրիչ՝ աշխատասեղանի պատկերակով)։ Առաջին անգամ պահանջվում է ինտերնետ (electron-builder-ը ներբեռնում է իր գործիքները)։

## Նախագծի կառուցվածքը

```
src/
  engine/    խաղի մաքուր տրամաբանությունը (առանց DOM-ի և Electron-ի), preview.js՝ նախադիտման օգնականներ
  ai/        գնահատում, քայլերի գեներացիա, Easy / Minimax / MCTS, բացատրություն, Web Worker
  data/      config.js (բոլոր կարգավորվող թվերը), cards.js, campaign.js
  ui/        ինտերֆեյս (DOM + CSS). audio.js՝ ձայն, fx.js՝ էֆեկտներ, aipanel.js՝ AI-ի վահանակ, screens/՝ էկրաններ
  electron/  main.js, preload.cjs
assets/      sprites.js (բոլոր նկարները), scenes.js (դաշտ, մենյու, քարտեզ, զինանշան), տառատեսակներ
tools/       selfplay.js, experiments.js, balance.js, ui-smoke.mjs, make-icon.js և օժանդակ գործիքներ
tests/       node:test թեստեր
docs/        RULES.md, AI.md, DECISIONS.md, FRIENDS.md, experiments/, screenshots/
build/       icon.ico, icon.png (electron-builder-ի համար)
```
