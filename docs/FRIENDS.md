# Արքաների Մարտ — ինչպես գործարկել

Խաղը աշխատում է Windows 10 և 11-ում, ինտերնետ պետք չէ։

## Տարբերակ 1. առանց տեղադրման

1. Պահիր `ArqaneriMart-1.4.1-portable.exe` ֆայլը ցանկացած պանակում (օրինակ՝ աշխատասեղանին)։
2. Կրկնակի սեղմիր ֆայլին։ Առաջին գործարկումը տևում է մի քանի վայրկյան։

## Տարբերակ 2. տեղադրիչով

1. Գործարկիր `ArqaneriMart-1.4.1-setup.exe` ֆայլը և հետևիր քայլերին։
2. Աշխատասեղանին կհայտնվի «Արքաների Մարտ» պատկերակը։

## Եթե Windows-ը զգուշացնում է

Ֆայլը ստորագրված չէ (դա վճարովի է), ուստի Windows-ը կարող է ցույց տալ կապույտ պատուհան՝ **«Windows protected your PC»**։ Սեղմիր **More info**, հետո **Run anyway**։

## Կառավարում

| Գործողություն | Ինչպես |
| --- | --- |
| Ընտրել քարտ | սեղմել քարտին կամ `1`–`4` ստեղները |
| Դնել քարտը | սեղմել քո գոտու ընդգծված վանդակին կամ քաշել քարտը դաշտ |
| Չեղարկել ընտրությունը | `Esc` կամ մկնիկի աջ կոճակ |
| Ավարտել պլանավորումը | «Պատրաստ է» կոճակ, `Space` կամ `Enter` |
| Քարտի կամ զորքի տեղեկություն | `I` (մկնիկը վրան պահած) կամ աջ կոճակ զորքի վրա |
| Ձայնն անջատել / միացնել | `M` |
| Ամբողջ էկրան | `F11` |

## Խորհուրդներ

- Սկսիր **Արշավից**. առաջին մարտը ուսուցողական է և քայլ առ քայլ բացատրում է կանոնները։
- Դրված քարտը հետ չի վերցվում, իսկ չծախսած ոսկին մնում է հաջորդ ռաունդին։
- Հեռահար զորքերը (աղեղնավոր, պարսատիկավոր) պահիր ամուր զորքերի հետևում։
- Մարտի ժամանակ աջ կողմի վահանակը ցույց է տալիս, թե ինչ էր մտածում AI-ը։
- Ձայնը, ժամաչափը և անիմացիայի արագությունը փոխվում են «Կարգավորումներ» բաժնում։

Առաջընթացը պահվում է քո համակարգչում՝ `%APPDATA%\ArqaneriMart\save.json` ֆայլում։
